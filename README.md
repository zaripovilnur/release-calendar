# Календарь релизов YADRO

Внутренний сервис для команды маркетинга: календарь выхода продуктов, карточки продуктов со ссылками, файлами и командой.

Сейчас в репозитории лежит **ТЗ и макет** — код напишет Claude Code.

## Что внутри

- `docs/TZ.md` — техническое задание
- `CLAUDE.md` — правила для Claude Code (он читает этот файл сам)
- `design/index.html` — эталонные экраны, открываются двойным кликом в браузере
- `design/source/` — исходники макета
- `design/assets/` — логотипы
- `data/seed.json` — продукты и сроки на 2027 год из таблицы
- `data/demo.json` — пример материалов для сверки дизайна

## Как запустить разработку

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте папку в VS Code.
3. Запустите Claude Code в терминале VS Code и напишите:

   > Прочитай CLAUDE.md и docs/TZ.md и реализуй сервис полностью по ТЗ. Дизайн один в один с design/screens. Ничего не добавляй от себя.

4. Когда Claude Code закончит, запустите в терминале:

   ```
   npm install
   npm run seed
   npm run seed:demo
   npm start
   ```

5. Откройте в браузере `http://localhost:3000` и сравните с `design/index.html`.
6. Для проверки дизайна автоматически: `npm test`.

Логин и пароль администратора задаются в файле `.env` (образец — `.env.example`).
