# Инструкция для Claude Code

Ты реализуешь сервис «Календарь релизов» YADRO по ТЗ `docs/TZ.md`.

## Обязательные правила

1. Перед началом работы полностью прочитай `docs/TZ.md` и открой все эталоны в `design/screens/`.
2. Дизайн переносится **один в один** с эталонов `design/screens/*.html`: разметка, инлайн-стили, тексты, иконки. Вычисленные стили элементов в приложении должны совпадать с эталоном.
3. **Ничего не добавляй от себя**: никаких новых кнопок, полей, окон, анимаций, текстов, библиотек интерфейса и «улучшений». Если чего-то нет в ТЗ и эталонах — не делай. Где ТЗ прямо говорит использовать нативные `confirm()`, `alert()`, `prompt()`, `<select>`, `<input type="color">` — используй их.
4. Если ТЗ и эталон расходятся или что-то неясно — остановись и спроси, не додумывай.
5. Стек строго из раздела 2 ТЗ: Node.js 20, Express, better-sqlite3, multer, express-session, bcryptjs, чистые HTML/CSS/JS без фреймворков и сборщиков.
6. Готовность проверяется визуальными тестами из раздела 12: `npm test` должен проходить для всех эталонов.

## Порядок работы

1. Каркас проекта, `package.json`, `.env.example`, схема БД, `npm run seed` и `npm run seed:demo`.
2. API и вход администратора.
3. Страницы по порядку: календарь → все продукты → файлы и ссылки → карточка продукта → модальные окна → телефон.
4. Визуальные тесты Playwright и правки до совпадения с эталонами.
5. `README.md` с командами запуска.
