# Календарь релизов YADRO

Внутренний сервис для команды маркетинга: календарь выхода продуктов, карточки продуктов со ссылками, файлами и командой, режим администратора.

## Что нужно

- Node.js 20 или новее

## Первый запуск

1. Скопируйте файл `.env.example` в `.env` и впишите свои логин и пароль администратора (`ADMIN_LOGIN`, `ADMIN_PASSWORD`), а в `SESSION_SECRET` — любую длинную случайную строку.
2. В терминале, в папке проекта:

   ```
   npm install
   npm run seed
   npm start
   ```

3. Откройте в браузере `http://localhost:3000`.

`npm run seed` создаёт базу и загружает продукты и сроки из `data/seed.json`.
**Внимание:** повторный `npm run seed` стирает всё, что добавлено через интерфейс (продукты, ссылки, файлы), — запускайте его только для первой загрузки.

Для сверки с эталонными экранами можно дополнительно загрузить демо-материалы TATLIN.UNIFIED G3:

```
npm run seed:demo
```

## Проверка дизайна

```
npm test
```

Тест сам поднимает сервис на отдельной временной базе (рабочие данные не трогает), открывает каждый эталон из `design/screens/` и ту же страницу приложения, делает снимки и сравнивает их. Допуск — 1 % отличающихся пикселей. Отчёт с картинками отличий: `npx playwright show-report`.

## Где что лежит

- `docs/TZ.md` — техническое задание
- `design/index.html` — эталонные экраны, открываются двойным кликом
- `server/` — сервер: база (`db.js`), загрузка данных (`seed.js`), вход администратора (`auth.js`), страницы и API (`index.js`)
- `public/` — страницы, стили и скрипты интерфейса
- `storage/` — база `app.db` и загруженные файлы (в git не попадает, делайте резервную копию этой папки)
- `tests/visual.spec.js` — визуальные тесты

## Настройки (`.env`)

| Переменная | Что это | По умолчанию |
|---|---|---|
| `PORT` | порт сервиса | `3000` |
| `SESSION_SECRET` | секрет для входа администратора | учебное значение — замените |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | первый администратор, создаётся при `npm run seed` | `admin` / `admin` — замените |
| `UPLOAD_DIR` | папка для файлов | `./storage/uploads` |
| `MAX_UPLOAD_MB` | наибольший размер файла | `200` |

## Шрифт

Сейчас используется Manrope из Google Fonts. Когда будут файлы TT Norms Pro (Regular, Medium, Light), положите их в `public/fonts/` и раскомментируйте блок `@font-face` в `public/css/tokens.css`.
